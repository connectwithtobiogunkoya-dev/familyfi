# FamilyFi

A family finance app by Hearth Labs. A household keeps a shared family wallet and moves money into labelled pots such as rent, school fees and groceries.

FamilyFi runs in a test environment. No real money moves. It is not a bank: balances are test money, and the bank account money comes from is simulated.

Built in public as part of a 90-day challenge, with Claude Code as the coding partner.
